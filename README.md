# CV interactivo de Julián Rojano

Página web estática lista para publicar con **GitHub Pages**.

## Archivos
- `index.html`: página completa. Incluye la fotografía integrada, la animación de lanzamiento y explosión, y el currículum. No necesita carpetas de imágenes ni dependencias externas.

## Publicar con GitHub Pages
1. Entra en https://github.com/ e inicia sesión.
2. Crea un repositorio nuevo, por ejemplo `cv-julian`.
3. Sube `index.html` (puedes subir también este README).
4. En el repositorio, abre **Settings → Pages**.
5. En **Build and deployment**, selecciona **Deploy from a branch**.
6. Elige la rama `main` y la carpeta `/ (root)`, y pulsa **Save**.
7. Espera a que GitHub Pages publique la web. El enlace aparecerá en esa misma sección y tendrá un formato parecido a `https://TU-USUARIO.github.io/cv-julian/`.

## Vista previa local
Abre `index.html` en un navegador moderno.

## Nota
Antes de hacerlo público, revisa que quieres mostrar los datos personales y de contacto incluidos en el currículum.
